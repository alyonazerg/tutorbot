# Tutor bot — учёт занятий, оплат и словарь для репетитора

Telegram-бот для частного преподавателя: ученики, пакеты занятий, оплаты,
расписание, готовые сообщения для пересылки ученику и словарь с интервальным
повторением по принципу Anki.

Написан на чистом Python 3 без внешних библиотек — только стандартная библиотека.
Все данные лежат в одном файле SQLite, наружу ничего не уходит, кроме запросов
к Telegram API.

## Что умеет

**Ученики и деньги**
- несколько учеников, переключение кнопками, архив без потери данных;
- пакеты 1 / 4 / 8 занятий или своё число;
- оплаты: количество занятий, сумма и дата;
- ставка за занятие для каждого ученика отдельно, две заготовки
  (2000 ₽ / 60 мин и 1500 ₽ / 45 мин) и своя;
- остаток оплаченных занятий и долг, если провели больше оплаченного;
- автоматическое напоминание преподавателю, когда у ученика остаётся
  последний оплаченный урок, с готовым текстом для пересылки;
- итоги месяца таблицей: занятия, оплаты, остатки по всем ученикам;
- выгрузка занятий, оплат и слов в CSV.

**Занятия и расписание**
- отметка проведённого занятия сегодня или другой датой, тема и ДЗ;
- отмена занятия со списанием и без списания;
- постоянное расписание («пн 17:00, чт 18:30») и разовые даты
  для тех, с кем договариваетесь на неделю вперёд;
- перенос конкретного занятия на другую дату и время;
- прогноз, на какую дату придётся последнее оплаченное занятие;
- расписание таблицей: постоянное по дням недели и ближайшая неделя;
- утренний дайджест «сегодня занятия у …».

**Словарь и повторение**
- слова добавляют и преподаватель, и ученик, по строке на слово:
  `apple - яблоко` (разделители: тире, двоеточие, табуляция);
- карточки с кнопками «❌ Не помню / 🙂 Помню / 😎 Легко», упрощённый SM-2:
  «не помню» возвращает слово в конец сегодняшней очереди, дальше интервалы
  растут (1 день → 2–3 → неделя → две → месяц);
- ежедневное напоминание ученику: «пора повторить N слов»;
- удаление отдельных слов — и преподавателем, и учеником;
- преподаватель может вести собственный словарь («📚 Мой словарь»)
  и участвовать в общем рейтинге.

**Прогресс и рейтинг**
- по каждому ученику: всего слов, выучено, доля выученных, в работе,
  повторов за неделю, дней с занятиями из 30, дней подряд, доля ответов
  «помню», дата последнего повторения;
- рейтинг: у преподавателя с настоящими именами, у учеников — под никами,
  которые они выбирают сами.

**Доступ ученика**
- два кода: полный (занятия, ближайшие даты, словарь) и детский (только словарь);
- ученик проверяет ближайшие занятия кнопкой или командой `/when`;
- любой посторонний, написавший боту, видит визитку преподавателя
  с кнопкой записи на занятия;
- у ученика есть кнопка «💌 Поделиться ботом» — бот присылает готовое
  сообщение о преподавателе со ссылкой на бота.

## Команды преподавателя

| Команда | Что делает |
|---|---|
| `/students` | список учеников |
| `/new Аня` | добавить ученика |
| `/s Аня` | открыть карточку |
| `/done`, `/done 15.09` | записать занятие |
| `/pay 4 4000` | оплата: 4 занятия, 4000 |
| `/week` | ближайшая неделя |
| `/schedule` | постоянное расписание |
| `/month` | итоги месяца |
| `/mywords` | свой словарь |
| `/export` | выгрузка CSV |
| `/db` | где лежит база и сколько в ней записей |
| `/id` | ваш Telegram ID |

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `TG_BOT_TOKEN` | да | токен от @BotFather |
| `TG_OWNER_ID` | желательно | ваш Telegram ID (`/id`); без него кнопки педагога доступны всем |
| `TG_BOT_DB` | на хостинге — да | путь к базе на постоянном диске, например `/data/tutor.db` |
| `TG_DIGEST_HOUR` | нет | час утренних напоминаний по времени сервера, по умолчанию 9, `0` — выключить |

## Запуск локально

```bash
export TG_BOT_TOKEN="123456:AA..."
export TG_OWNER_ID="123456789"
python3 main.py
```

## Запуск на хостинге (Bothost и подобные)

1. Загрузить репозиторий на GitHub и подключить его к хостингу, ветка `main`.
2. Язык Python 3, команда запуска `python main.py`.
3. Прописать переменные окружения из таблицы выше.
4. **Постоянный диск обязателен.** Без него файл базы стирается при каждом
   перезапуске. Подключите Volume, узнайте путь монтирования (обычно `/data`)
   и укажите его в `TG_BOT_DB`.
5. Проверка: команда `/db` показывает путь к базе и количество записей.
   Заведите тестового ученика, перезапустите бота, снова отправьте `/db` —
   если данные на месте, всё настроено верно.

## Настройка под себя

В начале `main.py`:
- `TEACHER_HANDLE` — ник в Telegram для кнопки записи на занятия;
- `TEACHER_BIO` — текст визитки;
- `RATE_PRESETS` — заготовки ставок;
- `LEARNED_IVL` — с какого интервала слово считается выученным (по умолчанию 21 день).

## Если что-то сломалось

- Бот присылает ошибки прямо в Telegram владельцу: текст ошибки, строку кода
  и нажатую кнопку. Логи хостинга смотреть не обязательно.
- Если сообщение не удалось отправить, бот пишет причину ответа Telegram
  в самой карточке.
- Резервная копия: команда `/export` присылает CSV со всеми занятиями,
  оплатами и словами.
