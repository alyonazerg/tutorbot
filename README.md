# Tutor bot — учёт занятий и оплат для репетитора

Telegram-бот для частного преподавателя: ученики, пакеты занятий, оплаты,
расписание и готовые сообщения для пересылки ученику.

Написан на чистом Python 3 без внешних библиотек — только стандартная библиотека.

## Возможности

- несколько учеников, переключение кнопками, архив;
- пакеты 1 / 4 / 8 или своё число, ставка за занятие и автоподсчёт суммы;
- оплаты: количество занятий + сумма + дата;
- отметка проведённых занятий (сегодня или другой датой), тема занятия и ДЗ;
- отмена занятия со списанием и без списания;
- остаток оплаченных занятий, долг, если провели больше оплаченного;
- расписание («пн 17:00, чт 18:30») и прогноз, когда закончится пакет;
- перенос занятия на другую дату и время;
- две ставки на выбор (2000 ₽ / 60 мин и 1500 ₽ / 45 мин) или своя, отдельно для каждого ученика;
- подтверждающее сообщение после каждой записи;
- автоматическое напоминание преподавателю, когда у ученика остаётся последний оплаченный урок;
- сообщения для пересылки ученику: выписка, напоминание об оплате, расписание;
- расписание таблицей: постоянное по дням недели и ближайшая неделя;
- итоги месяца по всем ученикам таблицей;
- утренний дайджест «сегодня занятия у …»;
- личный доступ для ученика по коду: он видит проведённые и остаток занятий;
- словарь слов (слово — перевод), добавляют преподаватель и ученик;
- интервальное повторение слов по принципу Anki: карточки с кнопками
  «не помню / помню / легко» и напоминание ученику в нужные дни;
- выгрузка занятий, оплат и слов в CSV.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `TG_BOT_TOKEN` | да | Токен бота от @BotFather |
| `TG_OWNER_ID` | желательно | Ваш Telegram ID, чтобы боту отвечали только вы. Узнать: команда `/id` |
| `TG_BOT_DB` | на хостинге — да | Путь к файлу базы, например `/data/tutor.db` (постоянный диск) |
| `TG_DIGEST_HOUR` | нет | Час утреннего дайджеста, по умолчанию 9. `0` — выключить |

## Запуск локально

```bash
export TG_BOT_TOKEN="123456:AA..."
export TG_OWNER_ID="123456789"
python3 main.py
```

## Запуск на Bothost

1. Загрузить этот репозиторий на GitHub.
2. В Bothost создать бота, подключить GitHub-репозиторий, ветка `main`.
3. Язык — Python 3, команда запуска: `python main.py`.
4. В настройках прописать переменные окружения из таблицы выше.
5. Важно: на бесплатном тарифе данные стираются при перезапуске.
   Для постоянного хранения нужен тариф с дисковым хранилищем (Volume)
   и переменная `TG_BOT_DB`, указывающая на путь внутри этого хранилища,
   например `/data/tutor.db`.

Резервная копия: команда `/export` присылает все занятия и оплаты файлом CSV.

## Данные

Всё хранится в одном SQLite-файле. Никаких внешних сервисов бот не использует,
данные никуда не отправляются, кроме Telegram API.
