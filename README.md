# What's next? — бот-помощник репетитора

Телеграм-бот для учёта частных занятий: ученики, оплаты, расписание, домашние
задания, материалы и словарь с интервальным повторением. Преподаватель ведёт всё
кнопками в своём чате, ученик получает свой личный кабинет в том же боте.

Один файл, только стандартная библиотека Python 3.8+, база — SQLite.

---

## Что умеет

**Для преподавателя**

- Карточки учеников: расписание, остаток оплаченных занятий, ставка, заметки.
- Отметка проведённых занятий (сегодня или задним числом), отмены и переносы.
- Оплаты и итоги месяца, выгрузка всего в CSV.
- Домашние задания — уходят ученику в бот сразу после сохранения.
- Материалы: ссылки, файлы и бонусы, которые ученик открывает за «ключики».
- Своя ссылка на занятие у каждого ученика.
- Утренний список занятий на сегодня и обзор ближайшей недели.
- Словарь ученика, слова можно добавлять пачкой, по одному в строке.
- Питомец-тамагочи: растёт от повторений, напоминает ученику о практике.
- Упражнения от ИИ по лексике ученика, которые он открывает за ключики.
- Оформление сырых слов в полные карточки: транскрипция, определение, синонимы, пример.
- Учёт расхода токенов ИИ по типам задач и по ученикам (`/ai`).
- Разминка (warm-up) к занятию: быстрая, полная или по заданной грамматике/теме.
  Строится на лексике ученика, его трудных словах, домашке и заметках с занятий.

**Для ученика**

- Кнопка подключения к своему занятию.
- Ближайшее занятие, домашка, слова к уроку, остаток оплаченных занятий.
- Материалы от преподавателя и отзывы в обе стороны.
- Тренажёр слов с повторением по расписанию, прогресс и рейтинг.
- Питомец, которого кормят повторениями: пять слов в день — и он сыт.

## Установка

### 1. Бот в Telegram

Создайте бота у [@BotFather](https://t.me/BotFather), сохраните токен.

### 2. Хостинг (Bothost)

Загрузите файлы в репозиторий GitHub и подключите его к боту в панели Bothost.
Точка входа — `main.py`, зависимостей ставить не нужно.

### 3. Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TG_BOT_TOKEN` | да | токен от @BotFather |
| `TG_OWNER_ID` | желательно | ваш Telegram ID, узнать командой `/id` |
| `TG_BOT_DB` | **да, на хостинге** | путь к базе, на Bothost — `/app/data/tutor.db` |
| `TG_DIGEST_HOUR` | нет | час утреннего списка занятий, по умолчанию 9, `0` — выключить |
| `TG_BACKUP_HOUR` | нет | час ежедневной копии базы, по умолчанию 22, `0` — выключить |
| `TG_PET_HOUR` | нет | час напоминания про питомца, по умолчанию 18, `0` — выключить |
| `AI_KEY` | нет | ключ ИИ для разминок; без него используется шаблон |
| `AI_FORMAT` | нет | `anthropic` или `openai` (любой OpenAI-совместимый сервис) |
| `AI_MODEL` | нет | название модели |
| `AI_URL` | нет | адрес эндпоинта, для формата `openai` обязателен |
| `TG_AI_BUDGET` | нет | всего токенов на ИИ, по умолчанию 1 000 000 |
| `TG_AI_DAILY` | нет | дневной потолок токенов, по умолчанию 40 000 |

### 4. Первый запуск

Напишите боту `/start`, затем `/id` и впишите полученное число в `TG_OWNER_ID`.
Проверьте `/db` — путь должен показывать `/app/data/...`.

## Где хранятся данные

Вся информация лежит в одном файле SQLite. **Он обязан находиться вне папки с
кодом**: при каждом обновлении из Git контейнер пересобирается с нуля, и всё,
что лежит рядом с `main.py`, исчезает. На Bothost для этого есть папка `/app/data`
— она создаётся автоматически и из синхронизации с Git исключена.

Схема базы обновляется сама при запуске: новые колонки и таблицы добавляются к
существующим данным, ничего переносить вручную не нужно.

Файл базы не должен попадать в репозиторий. В `.gitignore`:

```
data/
*.db
*.db.old
*.db.snapshot
```

---

## Резервные копии

- `/backup` — бот присылает файл базы в чат с подписью, сколько там карточек,
  занятий, оплат и слов.
- Раз в сутки копия приходит сама, час задаётся в `TG_BACKUP_HOUR`.
- `/restore` — отправьте команду, затем перешлите боту `.db`-файл. Бот проверит
  целостность файла и наличие нужных таблиц и только потом заменит базу.
  Прежняя сохранится рядом с расширением `.old`.
- Если бот запустился с пустой базой, он сам напишет об этом владельцу.

Копия снимается штатным механизмом SQLite, поэтому файл целый, даже если бот в
этот момент пишет в базу.

## После занятия

Кнопка «✅ Провела» не просто записывает занятие, а открывает короткую цепочку: тема
урока, домашнее задание, слова с занятия. Каждый шаг необязателен, но домашка и слова
сразу уходят ученику в бот — домашка отдельным сообщением, слова списком с кнопкой
«Повторить сейчас». Экран показывает, что уже заполнено, так что видно, чего не хватает.

## Как подключить ученика

В карточке ученика нажмите «Пригласить» — бот выдаст код. Ученик открывает бота,
жмёт «У меня есть код» и вводит его. После этого он видит свой кабинет, а вы —
отметку «подключён» в карточке.

Для детей есть облегчённый доступ: только словарь, прогресс и ссылка на занятие,
без оплат и отзывов.

## Материалы и ссылки

Ссылку можно прислать текстом (`Учебник Evolve 5 — https://…`) или вставить так,
как её копирует телефон, когда адрес спрятан под названием — бот поймёт оба
варианта. Строка, начатая словом `всем`, добавляет материал всем ученикам сразу.
Файлы сохраняются по кнопке «Загрузить файл»: бот запоминает их и пересылает
ученику по запросу. О каждом новом материале ученик получает уведомление.

---

## Словарь и карточки

Повторение устроено как в Anki: четыре кнопки — Снова, Трудно, Хорошо, Легко — и на
каждой подписан интервал, через который слово вернётся. Интервалы считаются по
упрощённому SM-2 с фактором лёгкости.

При добавлении слов бот прогоняет их через ИИ: исправляет опечатки (strick → strict),
приводит к начальной форме (running → run) и проверяет перевод. Что именно поправлено,
он показывает в ответе, так что ошибки учеников видны сразу.

Во время повторения слово можно удалить кнопкой «🗑 Удалить слово» — бот переспросит,
потому что вместе с карточкой стирается и её история повторений.

Уровень преподавателя для собственного словаря по умолчанию C2: определения и примеры
приходят взрослые, без упрощений. Меняется командой `/level B2` и т.п.

Сырые слова (без перевода) можно оформить одним запросом к ИИ: он добавит
транскрипцию, определение по-английски, синонимы, антонимы, типичное сочетание,
пример и перевод. В личном словаре преподавателя лицевая сторона карточки —
определение по-английски, оборот — полная карточка. У учеников лицевая сторона —
само слово.

## Warm-up

Кнопка «🔥 Warm-up» в карточке ученика даёт три варианта: быстрая разминка (5 минут),
полная (10–15 минут) и разминка по заданной грамматике или теме. ИИ получает контекст:
активную лексику ученика, слова, которые он чаще всего забывает, текущее домашнее
задание, заметки с последних занятий и уровень. Материал приходит блоками LEAD-IN,
LEXIS, COLLOCATIONS, GRAMMAR, SPEAKING и KEY — его можно вести прямо с экрана.
Без ИИ бот собирает разминку по шаблону, как раньше.

Под каждым ответом ИИ есть кнопка «✏️ Дополнить или переделать»: бот помнит последний
запрос и свой ответ, поэтому можно дописать «сделай сложнее», «добавь пять предложений
на Passive», «убери говорение» — и получить переделанный вариант целиком. Дополнять
можно сколько угодно раз подряд, каждый следующий ответ снова становится последним.

## Упражнения за ключики

Ученик тратит 🔑 ключик и получает задание, составленное ИИ по его собственным словам:
перевод фраз, слово в контексте, поиск ошибки, сочетаемость, мини-диалог.

Отвечать можно двумя способами. 🔘 — вопросы с вариантами: бот показывает их по одному,
ученик жмёт A, B или C, сразу видит разбор и в конце счёт. Такой формат проверяется
внутри бота, без второго запроса к ИИ, и обходится вдвое дешевле. ✍️ — письменный:
ответы одним сообщением, разбор делает ИИ. «Слово в контексте» — только кнопками,
перевод и диалог — только письменно, остальные доступны в обоих форматах.

Если ИИ не ответил, ключик возвращается.

Ключики выдаются за: полностью повторённый день (не чаще раза в неделю), новую стадию
питомца, серию без пропусков (7, 14, 30, 60, 100 дней), победу в недельном рейтинге —
и вручную из карточки ученика. Так расход токенов ограничен сверху механикой, а не
только лимитами.

Длинные материалы бот разбивает на несколько сообщений, а если ответ модели оборвался
на середине, показывает кнопку «▶️ Продолжить».

Расход виден по команде `/ai`: сегодня, за неделю, за месяц, всего из бюджета, разбивка
по типам задач и по ученикам. При достижении 75% и 90% бюджета бот предупредит.
Уровень ученика (A1–C2) задаётся в карточке и влияет на сложность заданий.

## Еженедельная сводка

По понедельникам утром на каждого ученика приходит сводка: сколько повторений и за
сколько дней, сколько упражнений, какие слова чаще всего забывались. Если ученик писал
упражнения, ИИ добавляет разбор — повторяющиеся ошибки, что уже получается, и три темы
для отработки на занятии. Сводку можно запросить в любой момент кнопкой «📊 Сводка за
неделю» в карточке ученика.

Письменные ответы и разборы хранятся в таблице `ex_log` — именно из них собирается эта
часть сводки.

## Питомец

У каждого ученика есть питомец, который растёт от повторений: 🥚 → 🐣 → 🐥 → 🦜 → 🦉.
Стадия зависит от общего числа повторений, настроение — от того, занимался ли ученик
сегодня и как давно заходил. Пять повторений в день (или все слова, назначенные на
сегодня) — питомец сыт. Ничего не хранится, кроме имени: состояние каждый раз
считается из журнала повторений, поэтому его нельзя «сломать» и незачем чинить.

Питомец не умирает и не болеет — если ученик пропал, тот просто засыпает и ждёт.
Вечером, если ученик ещё не занимался, бот один раз мягко напоминает; час задаётся
в `TG_PET_HOUR`. О переходе на новую стадию приходит поздравление.

## Частые вопросы

**После обновления из Git всё пропало.** Не задана `TG_BOT_DB`, либо путь ведёт
внутрь папки с кодом. Пропишите `/app/data/tutor.db` и восстановитесь из
последней копии через `/restore`. Заодно проверьте, что файла `.db` нет в
репозитории: если он туда попал, каждый деплой будет возвращать старую версию.

**ИИ не отвечает.** Отправьте `/aitest` — бот покажет модель, текст ошибки от сервиса
и подсказку. Частые причины: неверное имя модели в `AI_MODEL`, ключ с лишним пробелом,
нулевой баланс, слишком долгий ответ у самых больших моделей. Полная история расхода и
последняя ошибка — в `/ai`.

**Ученик не получает сообщения.** Он не подключён к боту — в карточке не будет
отметки «подключён ✅». Выдайте ему код приглашения.
